# Historical implementation and qualification reports

These snapshots preserve the original milestone prose before documentation was
consolidated on 2026-09-19. They intentionally retain past statements, including
superseded settings and incomplete features. Relative Markdown links were rebased;
measurements, commands and artifact paths were otherwise preserved.

Use the [current architecture](../ARCHITECTURE.md), [Doom guide](../../examples/doom/README.md),
[chess guide](../../examples/chess/README.md) and [verification guide](../../VERIFICATION.md)
for current instructions. The [completion checklist](../../COMPLETION-CHECKLIST.md)
tracks remaining work.

The archive date is not the execution date. Local evidence paths under `artifacts/`
remain exactly as reported; those files are ignored by Git and are not bundled
here. Historical passing results require their original evidence or a new run
before being treated as current verification.
